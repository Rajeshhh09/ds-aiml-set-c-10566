## Task 1 — Statistics and Linear Algebra

### M1 — Descriptive Statistics

Descriptive statistics are calculated from the observed distance values in the 192 fit records only. Missing values are excluded from this analysis. The summary includes:

- Number of observed values
- Mean
- Median
- Sample standard deviation with ddof = 1

A histogram of the observed distance values is generated and saved to outputs/figures/distance_histogram.png.

### M2 — Welch Two-Sample t-Test

A two-sided Welch independent-samples t-test is used to compare the distance values between groups G1 and G2. The hypotheses are:

- Null hypothesis: the population mean distance is equal across both groups
- Alternative hypothesis: the population mean distance differs between groups

The significance level is alpha = 0.05, and the test is used because it does not assume equal variance between groups.

### M3 — Manual Covariance and Eigen Analysis

For this analysis, the fit records with complete values for both distance and traffic are used. The two-column matrix is centered by subtracting the column means, and the sample covariance matrix is computed using:

X_centered.T @ X_centered / (n - 1)

Eigenvalues and eigenvectors are calculated using a symmetric eigenvalue routine. The largest eigenvalue and its matching eigenvector identify the principal direction with the greatest variance.

## Task 2 — Data Preprocessing

All preprocessing objects are fitted using only the 192 fit records. The validation and test sets are transformed using the fitted preprocessing objects.

### Numeric Features

The original numeric predictors are:

- distance
- load
- traffic
- staff

Missing numeric values are handled using median imputation. The imputer is fitted only on the fit partition.

### Engineered Feature

After numeric imputation, the following engineered feature is created:

- engineered_feature = load / (staff + 1)

This feature is computed before scaling and on the original imputed numeric scale.

### Categorical Encoding

The categorical feature group is transformed using one-hot encoding. The encoder is configured to handle previously unseen categories without failure and is fitted only on the fit partition before being reused for validation and test data.

### Feature Scaling

Standard scaling is applied to the following variables:

- distance
- load
- traffic
- staff
- engineered_feature

The scaler is trained only on the fit records, while the one-hot encoded group columns remain unscaled.

The final transformed feature set contains:

- distance
- load
- traffic
- staff
- engineered_feature
- group_G1
- group_G2

This yields a final model input with 7 transformed features. The fitted preprocessing objects are saved in models/preprocessing.pkl.

## Task 5 — Deep Learning Using ANN

### ANN Architecture

A dense feed-forward artificial neural network is implemented for binary classification. The architecture is:

- Input width: 7 transformed features
- Hidden layer 1: 16 neurons with ReLU activation
- Hidden layer 2: 8 neurons with ReLU activation
- Output layer: 1 neuron with sigmoid activation

The random seed is set to 42.

### Compilation

The ANN is compiled using:

- Loss: Binary cross-entropy
- Optimizer: Adam
- Learning rate: 0.001

Sigmoid activation is appropriate for the output layer because the task is binary classification and the output can be interpreted as a class-1 probability between 0 and 1. Binary cross-entropy is appropriate because the target contains two classes represented as 0 and 1.

### ANN Training

The ANN is trained using:

- Fit records: 192
- Validation records: 48
- Maximum epochs: 50
- Batch size: 16
- Early stopping patience: 5
- Monitored metric: validation loss
- Restore best weights: Yes
- Random seed: 42

Early stopping prevents unnecessary training when validation loss stops improving. The best model weights are restored before the final test evaluation.

The training and validation loss curves are plotted and saved in outputs/figures/ann_loss_curve.png.
